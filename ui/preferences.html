Playback hotkeys

Click a shortcut, then press the key combination. These work inside IINA — in the main player window and in the playlist window. They do not work while IINA is in the background (macOS doesn't allow that from a plugin).

Press Esc while recording to cancel. Use the ✕ button to unbind. For printable keys, Shift is folded into the character (e.g. Shift+X shows as “X”).

Playlists

With auto-save on, every change to the playlist — adding, removing, reordering or sorting — is written back to the playlist you last saved or loaded in that window. Playlists imported from an external file are not auto-saved. Opening an unrelated file (which replaces the whole playlist) turns auto-saving off for that window instead of overwriting the saved playlist.

Show the playlist when a player opens

Keep it paused after the track loads for (seconds)

“Start paused” applies to loading or importing a playlist here and to opening an .m3u / .m3u8 / .pls file in IINA (Finder, File ▸ Open, or at launch): the first track is selected but not played. IINA resumes a loaded track by itself, so the plugin watches for that resume and undoes it — for the time set above. Raise it if a video or an online track still starts playing; while it runs, a Play pressed in the player window may be undone once (the plugin's own Play always works).

YouTube Music search

By default results keep YouTube Music's own relevance order. Sorting by play count puts the most played songs first — handy for telling an original from covers and re-uploads. Applies from the next search.

Online metadata (yt-dlp)

For YouTube and other sites the plugin asks yt-dlp for artist / album / track (mpv only forwards the title). It is auto-detected in common locations — set a custom path only if it isn't found.
